# Ossmark Media logo files

Vector logo exports for the brand guidelines. Not deployed with the site (the site uses
`src/assets/brand/`, which are the same shapes in a single "current color" fill).

| File | Use |
|---|---|
| `ossmark-lockup-black.svg` / `-white.svg` | Full logo: O mark above the wordmark. Default choice. |
| `ossmark-mark-black.svg` / `-white.svg` | O mark alone: avatars, favicons, small spaces. |
| `ossmark-wordmark-black.svg` / `-white.svg` | Wordmark alone: wide, short spaces (headers, footers). |

- Black is `#000000` (for light backgrounds); white is `#FFFFFF` (for black or dark photos).
- Each file is cropped tight to the artwork with its origin at 0,0. Add clear space around the logo when placing it.
- The source artwork is `public/brand/logo-source.png`.
